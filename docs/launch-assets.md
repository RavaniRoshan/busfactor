## Product Hunt description

BusFactor scans a repository and returns an operability verdict, a risk map, an OPERATE.md, and questions only the original author can answer. It is built for solo founders and small teams shipping AI-generated production code. The score is computed by deterministic code; the LLM explains and drafts. Every claim cites a file and line.

## Reply bank (top 10 objections)

1. "This is just a linter." BusFactor produces a verdict, a risk map, and an OPERATE.md, not style findings.
2. "The LLM will hallucinate." Scores are deterministic and claims require valid citations.
3. "My repo is private." Use the local CLI with your own key; source is not stored by default.
4. "It is too slow." p50 target is 90 seconds for 50k LOC.
5. "The score is arbitrary." The rubric is public and versioned.
6. "It shames developers." Named scores are opt-in and framed as handoff risk.
7. "Why not use Claude Code itself?" BusFactor is neutral across agents and produces a committed artifact.
8. "What about non-JS repos?" JavaScript/TypeScript and Python are supported first; others get a limited-analysis banner.
9. "Does it execute my code?" No, not in MVP or V1.
10. "How much does it cost?" Hosted scans target a median cost at or below $0.30.
